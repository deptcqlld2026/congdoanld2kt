# Hệ thống Quản lý Công đoàn Tổ LĐ 2 - KT
**Phiên bản:** v1.1  
**Quản trị:** Trần Công Đẹp  

### Chức năng chính:
1. **Thông báo:** Tự động lấy danh sách sinh nhật từ Google Sheets và hiển thị.
2. **Xác nhận:** ĐVCĐ xác nhận đã đọc thông báo qua MSNV.
3. **Thăm hỏi:** Đăng ký trực tuyến và quản lý hồ sơ điện tử.

### Kỹ thuật:
- **Frontend:** HTML5, CSS3, Firebase JS SDK.
- **Backend:** Google Apps Script (GAS).
- **Database:** Firebase Realtime Database (US Server).
- **Storage:** Google Drive & Telegram Cloud.
